# 06 待決問題

規劃文件（「刷題系統規劃」rev 19）沒寫到、寫得不一致、或列為「待決定」的地方都在這裡。其他規格檔在受影響處標 `〔待決 Q-xx〕`，**沒有替你做決定**。

## 怎麼用

1. 在每題的「決定：」後面填選項代號或文字，例如 `決定：a，有效期 30 天`。
2. 「建議」只是參考，規格沒有採用；以「決定」為準。
3. 「阻擋」列出的任務（見 [04-phase1-tasks.md](04-phase1-tasks.md)）要等該題決定才能開工。AI 代理遇到未決定的題目必須停下來問，不得自行選擇。
4. 決定後告訴 AI「Q-xx 已決定」，由它更新受影響的規格段落（DDL 中被註解的欄位、JSON Schema 的 `$comment` 等）。

文件「共通」寫「Spring Security + JWT 或 Google 登入」，「已決定事項」寫「Google 登入 + 自建帳密」。JWT 與 Google 登入不是二選一，兩處都沒決定登入後如何保持登入狀態。
